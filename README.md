# OCULAR ODYSSEY 3D 👁️ · 中医眼科学

**เกมเว็บสอบจักษุวิทยา 3D สีสดใส** สำหรับทบทวนบทเรียนอาจารย์จีน พร้อมคำศัพท์จีน/พินอิน/ไทย ระบบคะแนน และข้อสอบพร้อมเฉลย

![ตัวอย่างหน้าจอเกม Ocular Odyssey 3D](assets/preview.jpg)

## เล่นเกม

เปิด `index.html` ใน Chrome / Safari / Edge ได้โดยตรง เกมสร้างโมเดล WebGL **สามมิติจริง** โดยไม่ต้องติดตั้งแพ็กเกจและไม่พึ่ง CDN สำหรับโมเดลหรือการทำงานหลัก ลากบนโมเดลเพื่อหมุน หรือใช้ปุ่ม ↶ / ↷

หากเครื่องหรือเบราว์เซอร์ไม่รองรับ WebGL จะแสดงโมเดลจำลอง 2 มิติแทนเพื่อให้บทเรียนและเกมส่วนอื่นยังใช้งานได้

## รายการด่าน

| ด่าน | กิจกรรม |

| 03 裂隙灯检查 | ปรับความกว้าง/ตำแหน่ง slit beam และทำข้อสอบ |
| 04 检眼镜检查 | ฝึก 四左四右 และค้นหา macula / optic disc ในภาพก้นตาจำลอง |
| 05 临床辨证 | กะพริบตาบ่อย เยื่อบุตา กลุ่มอาการ TCM และความปลอดภัย |
| 06 耳穴压豆 | เกมกดจุดใบหู (จุดเกมสมมติ) และข้อสอบความรู้ |

- ใช้บนโทรศัพท์/แท็บเล็ต/คอมพิวเตอร์

- ไม่มีการเก็บข้อมูลสุขภาพส่วนบุคคลหรือการเชื่อมต่ออินเทอร์เน็ตสำหรับเกม

## นำขึ้น GitHub Pages ภายในไม่กี่นาที

1. ไปที่ GitHub แล้วสร้าง **Public repository** ชื่อ `ocular-odyssey-3d` (หรือชื่ออื่นตามต้องการ)
2. แตก ZIP แล้ว **อัปโหลดไฟล์ที่อยู่ในโฟลเดอร์** ทั้งหมดขึ้น root ของ repository ต้องให้ `index.html` อยู่ root ไม่ใช่ถูกซ้อนในโฟลเดอร์
3. ที่ GitHub repository ไปที่ **Settings → Pages**
4. ตั้ง **Build and deployment → Deploy from a branch → main → /(root)** แล้วกด **Save**
5. รอให้ GitHub Pages แสดง URL ในหน้าตั้งค่า ลิงก์จะมีรูปแบบ `https://USERNAME.github.io/ocular-odyssey-3d/`

ไม่ต้องรัน `npm install` ไม่ต้องใช้ฐานข้อมูล และไม่มี API key

## โครงสร้างไฟล์

- `index.html` หน้าเกม
- `styles.css` สไตล์และการตอบสนองต่อหน้าจอ
- `three-lab.js` WebGL 3D engine พร้อม procedurally generated iris / retina
- `game.js` กลไกเกม คะแนน แบบทดสอบ การนำทาง
- `knowledge.js` คำศัพท์/บทเรียน/ข้อสอบ (แก้ไขหรือเพิ่มคำถามได้)
- `assets/preview.jpg` ภาพตัวอย่างเกมที่ถ่ายจากหน้าจอที่รันทดสอบ
- `.nojekyll` เปิด GitHub Pages แบบ static ตรง ๆ

## ความแม่นยำและการใช้งานทางการแพทย์

เนื้อหาสร้างจาก **ส่วนของเสียงบรรยายและข้อความที่ผู้เรียนส่งในแชต** ซึ่งบางช่วงถอดเสียงภาษาจีนคลาดเคลื่อน โดยเฉพาะชื่อสูตรยาจีน จึงระบุเป็นเนื้อหาเพื่อการสอบ/ทบทวนและต้องยืนยันกับอาจารย์หรือตำราก่อนใช้จริง ภาพก้นตาและโมเดล 3D เป็นภาพสังเคราะห์เพื่อการศึกษา **ไม่ใช่อุปกรณ์การแพทย์ ไม่ใช่ภาพตาคนไข้จริง** จุดบนหูเป็นจุดสำหรับเล่นเกม ไม่ใช่ตำแหน่งฝังเข็มทางกายวิภาคจริง

บทความไม่ให้คำแนะนำการใช้ยา และไม่ควรใช้เกมเพื่อวินิจฉัย รักษา หรือแทนการฝึกหัตถการกับผู้สอน
