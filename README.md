# Eye Pet Academy 🐾 · 眼科小伙伴

เกมเว็บทบทวน **第八章（5–10节）** จักษุแพทย์จีน อ้างอิงจากไฟล์สไลด์ที่ผู้ใช้ให้ โดย **ไม่รวมการปฏิบัติตรวจตาสัปดาห์หน้า**

## เริ่มเล่น

เปิด `index.html` ในเบราว์เซอร์ได้เลย (แนะนำ Chrome/Safari/Edge พร้อมอินเทอร์เน็ตเพื่อโหลดภาพสัตว์ 3D และฟอนต์) หากโหลด 3D ไม่สำเร็จ จะมีสัตว์อีโมจิเป็นภาพสำรอง และเกมยังใช้งานได้ตามปกติ

## วิธีเผยแพร่ด้วย GitHub Pages

1. สร้าง **Public repository** บน GitHub เช่น `eye-pet-academy`.
2. อัปโหลด **ทั้งสามไฟล์** `index.html`, `style.css`, `app.js` ลงในหน้าแรก (root) ของ repo.
3. เปิด **Settings → Pages → Build and deployment → Deploy from a branch**.
4. เลือก branch `main` และ folder `/(root)` แล้วกด **Save**.
5. เมื่อ Pages เผยแพร่ จะใช้ลิงก์รูปแบบ `https://USERNAME.github.io/eye-pet-academy/`.

หากต้องการดูเว็บก่อนเปิดเผยแพร่ สามารถเปิด `index.html` โดยตรงได้เลย

## ระบบเกม

- **6 บท** ตามสไลด์: 眼丹, 上胞下垂, 胞轮振跳, 椒疮, 粟疮, 目劄
- **24 การ์ดความรู้** ไทย/จีน/พินอิน แบ่งอ่านทีละการ์ด
- **30 คำถาม** ประจำบท + สุ่มสอบรวม 12 ข้อจากคลังเดียวกัน
- ตอบถูกแต่ละข้อ **ครั้งแรก +25 XP และสตรอว์เบอร์รี 1 ผล**; เรียนจบบทครั้งแรกโบนัส +10 XP
- เลเวลเพิ่มเมื่อ XP เพิ่มทุก 60 คะแนน
- สัตว์หกชนิด: โมจิแมว (Lv.1), กระต่ายปุยเมฆ (Lv.2), แพนด้าเป่าเปา (Lv.3), ฟ็อกซี่ (Lv.4), มังกรน้อย (Lv.5), ยูนิคอร์น (Lv.7)
- ลูบหัวหรือให้อาหารเพื่อเพิ่มความสุข และเลือกตัวที่ปลดล็อกแล้วได้
- มีสรุปเปรียบเทียบ 6 โรค และข้อสอบสุ่ม
- ความคืบหน้าเก็บด้วย `localStorage` ในเบราว์เซอร์ของผู้เล่น ไม่ได้ส่งไปยังเซิร์ฟเวอร์

## ที่มาและหมายเหตุ

ข้อมูลดึงจากสไลด์ **“第八章（5–10节）”** ที่ให้ในบทสนทนา รายชื่อกลุ่มอาการและตำรับสมุนไพรอ้างตามไฟล์ที่แนบ ไม่เติมสูตรใหม่ เกมเพื่อทบทวนบทเรียน ไม่ใช้เพื่อวินิจฉัยหรือแนะนำการรักษาจริง โดยเฉพาะ **眼丹** เป็นโรครุนแรง ต้องได้รับการประเมินจากแพทย์ทันที

ภาพ 3D สร้างขึ้นด้วย Three.js จากวัตถุทรงเรขาคณิต ไม่ใช้ภาพจากบุคคลที่สาม ไม่มีบัญชีผู้ใช้ ไม่มีโฆษณา ไม่มีการเรียก API ส่วนตัว
